# CLAUDE.md — правила проекта «Своя ферма / Лесная ягодка»

## Что это
Сайт + онлайн-запись с предоплатой + лист ожидания + магазин + админка PWA + бот-ассистент владельца.
Главная цель: клиент записывается без звонка за ≤ 60 с, а владелец тратит на запись ≤ 10 мин в день.

## Документы (читать по необходимости, не целиком)
- `docs/01-TZ.md` — ТЗ (источник правды по функциям)
- `docs/02-legal-152fz.md` — закон РФ → технические требования (приоритетнее ТЗ)
- `docs/03-design-brief.md` — токены, тон, компоненты
- `docs/04-agent-pipeline.md` — этапы, гейты 🚦, экономия токенов
- `docs/prompts/` — промпты этапов; `CHECKLIST.md` — очередь задач
- `docs/05-open-questions.md` — вопросы к владельцу; `docs/DECISIONS.md` — принятые решения

## Работа агентов
- Перед задачей — саб-агент `scout`; реализация — `builder`; проверка — `reviewer` (+ `qa-e2e`/`legal-auditor`/`seo-auditor` по тегам).
- Одна задача = один коммит `feat|fix|chore(<область>): <ID> <кратко>`.
- Не более 3 кругов review→fix; иначе `[!]` с описанием блокера в CHECKLIST.md.

## Код
- Монорепо на шаблоне vibe: `backend/` (Bun, Hono, Prisma, Postgres 18), `webapp/` (React/Vite), `website/` (Astro), `packages/contracts` (Zod), `infra/` (Terraform, Yandex Cloud).
- Деньги — `Int` копейки (`*Kop`). Время — `timestamptz` UTC; UI в `Europe/Moscow` / таймзоне локации.
- Все входы API валидируются Zod-схемами из `packages/contracts`.
- Доменная логика (слоты, брони, релизы, лист ожидания, политики, согласия) — чистые функции + тесты-таблицы; сначала тест.
- Двойная бронь невозможна на уровне БД (exclusion constraint); webhook'и и джобы идемпотентны.
- UI-тексты и ошибки — на русском, тон тёплый, без канцелярита.

## Нельзя
- Отправлять ПДн за пределы РФ: никаких Google Fonts/Analytics/reCAPTCHA/Sign-In, иностранных CDN и LLM с ПДн.
- Модальные попапы на сайте (кроме формы оплаты провайдера).
- Предустановленные чекбоксы согласий; маркетинговые сообщения без `Consent(MARKETING)`.
- Вход только по email/паролю (406-ФЗ) — только телефон +7 / VK ID / Яндекс ID.
- Публикация/рассылка от имени владельца без его подтверждения (кроме сервисных сообщений о записи).
- Выдуманные отзывы, рейтинги, цифры в текстах и разметке.

## Проверки перед сдачей задачи
`bun run typecheck && bun run lint && bun test` (+ `bun run build` для website/webapp). Вывод логов обрезать `| tail -60`.
