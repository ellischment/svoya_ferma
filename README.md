# Своя ферма / Лесная ягодка — сайт с онлайн-записью

Редизайн https://lesnaya-yagodka.ru: прежний стиль (лес, ягоды, жёлтые кнопки) остаётся, а сайт превращается из витрины на Tilda в систему, которая сама записывает, берёт предоплату, напоминает, переносит, предлагает освободившиеся места листу ожидания и соблюдает 152-ФЗ.

## Что здесь сейчас

## Как запустить
1. Ответить на `docs/05-open-questions.md` (можно частично).
2. Дизайн: отдать `docs/prompts/10-design-figma.md` в Claude с Figma.
3. Разработка: открыть репозиторий в Claude Code и вставить `docs/prompts/00-master-orchestrator.md`, затем `/loop` (текст в том же файле).
4. Отвечать только на гейтах 🚦.
