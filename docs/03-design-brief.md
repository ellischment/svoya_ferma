# 03. Дизайн-бриф (для Claude Design → Figma)

## 1. Идея
«**Лесная кладовая**»: тёплый деревенский дом у леса. Льняная скатерть, банка варенья на солнце, пучок трав. Узнаваемость сохраняем: оливковый заголовок капсом (Oswald), жёлтые кнопки-«таблетки», ягоды-иллюстрации по краям секций. Убираем хаос Zero-блоков, серый фон `#dbdbdb`, мелкие неконтрастные тексты и попапы.

Ощущение, которое должен вызывать сайт: *«Здесь спокойно, здесь обо мне позаботятся, записаться просто»*. Clean, trustworthy, local, без глянца и стоковых улыбок.

## 2. Палитра (проверена на WCAG, фон `#FBF8F1`)

Инструмент: https://www.realtimecolors.com/?colors=1f2a1c-fbf8f1-4f6b0c-ffe45c-a3244a&fonts=Oswald-Open%20Sans
(Исходная ссылка заказчика `2f27ce/433bff` — индиго SaaS-палитра. Лес и ягоды она не передаёт, поэтому используем инструмент, а не эти цвета.)

## 3. Типографика
- Заголовки: **Oswald** 400/500, uppercase только для H1/overline, letter-spacing 0.02em. Самохостинг, subset кириллица.
- Текст: **Open Sans** (как сейчас) или **Inter** (из ссылки заказчика). Рекомендация — Inter: лучше цифры в ценах и времени, tabular-nums для слотов. Самохостинг.
- Шкала (mobile → desktop): H1 32→56, H2 26→40, H3 20→28, body 17→18 (не меньше 16!), small 14. Межстрочный 1.5 для текста, 1.1 для заголовков.

## 4. Фактура и графика
- **Haikei** (https://haikei.app/generators/): «Layered Waves» / «Blob Scene» в `--secondary` → `--bg` как разделители секций (SVG ≤ 3 КБ каждый); «Low Poly Grid» не использовать. Экспорт SVG, цвета через токены.
- Ягоды из текущего сайта (ежевика, боярышник) как PNG → перевести в SVG/WebP, по 1–2 на секцию, частично за краем экрана, с параллаксом **только** если нет `prefers-reduced-motion`.
- Лёгкий шум бумаги (CSS noise, opacity 0.04).
- Фото: реальные, тёплый свет, руки, процесс, пар над чаем, фактура зефира. Соотношения 4:5 (карточки), 16:9 (hero десктоп), 3:4 (hero мобайл).
- Иконки: Lucide, stroke 1.75, скруглённые концы.

## 5. Компоненты (собрать в Figma как библиотеку с вариантами)
Button (primary-yellow / secondary-outline / ghost / sizes S-M-L / loading / disabled), StickyMobileBar, Header (mobile/desktop/scrolled), SlotChip (free / selected / few-left / disabled-with-reason), DayPicker (неделя), StepProgress, ServiceCard, EventCard (с «осталось N мест»), ProductCard (click-to-buy), PromoInlineBanner, ReviewQuote, FAQItem, ConsentCheckbox (с текстом-ссылкой), CookieBar, Toast, EmptyState, BottomTabBar (админка), AdminListRow с быстрыми действиями, Form fields (text/tel/select/textarea/price/duration-chips/photo-upload), Badge (статусы брони).

Радиусы: кнопки 999px (таблетка), карточки 20px, чипы 12px. Тени мягкие: `0 8px 24px rgba(31,42,28,.08)`. Отступы: шкала 4/8/12/16/24/32/48/64/96. Сетка: 4 колонки мобайл (16px поля), 12 колонок десктоп (макс. 1200px).

## 6. Экраны для Figma (приоритет)
1. Главная — mobile 390 и desktop 1440.
2. Мастер записи: 4 шага + успех + «слот заняли» + «нет слотов → лист ожидания» (mobile).
3. Страница услуги, страница мероприятия (mobile + desktop).
4. Афиша.
5. Магазин: карточка товара с click-to-buy (релиз 2).
6. Сообщения клиенту: макеты для MAX/SMS/email (подтверждение, напоминание, «место освободилось», спасибо).
7. Админка PWA (mobile): Сегодня, Расписание, Карточка услуги, Новое мероприятие, Акция, Гость, Настройки правил открытия записи.
8. Cookie-бар, правовые страницы (читабельная длинная типографика).
9. Тёмная тема для 1, 2, 7.

## 7. Микрокопирайт (голос: «от хозяйки», тёплый, на «вы», без канцелярита)
- CTA: «Записаться», «Выбрать время», «Забронировать и оплатить», «Купить билет», «Встать в лист ожидания», «Сообщить, когда откроется запись».
- Под CTA: «Без звонков · Подтверждение сразу · Перенос в 1 клик».
- Слот заняли: «Ой, это время только что забрали. Вот ближайшие свободные:».
- Нет слотов: «На эти даты всё занято. Оставьте номер — напишем первыми, если место освободится».
- Запись не открыта: «Запись на октябрь откроется 16 сентября в 22:00. Хотите, напомним?».
- Успех: «Ждём вас {день} в {время}! Всё, что нужно знать, отправили в {канал}».
- Никаких «Заявка отправлена, менеджер свяжется».
