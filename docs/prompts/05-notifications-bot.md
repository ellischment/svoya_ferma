# Промпт 05 — Сообщения клиентам и бот-ассистент владельца (builder)

```
Задача A (MVP): backend/src/notify по docs/01-TZ.md §8.5, §8.7, §8.8.
1. Интерфейс Channel { send(to, message): Result } и адаптеры: max (MAX Bot API), sms (SMS.ru/SMSC), email
   (SMTP: Unisender/Yandex 360), vk (VK API сообщения сообщества), telegram (опционально, флаг TELEGRAM_ENABLED,
   по умолчанию false — Telegram в РФ в 2026 работает с ограничениями). Все внешние вызовы с таймаутом и ретраями.
2. notify(clientId, templateKey, vars, {critical}) — порядок каналов из предпочтений клиента, фолбэк при ошибке
   или недоставке за 10 мин; SMS только если critical. Маркетинговые templateKey (флаг marketing=true) требуют
   Consent(MARKETING)=granted, иначе пропуск + лог. В рекламных — ссылка отписки.
3. Тихие часы 21:00–09:00 по таймзоне локации (кроме записи «на сегодня» и ответа на действие клиента).
4. Подписки на доменные события: booking.confirmed → «Вы записаны»; T-24ч, T-3ч напоминания с кнопками
   (inline-кнопки в MAX/VK/TG; в SMS/email — короткие ссылки на /m/:token); waitlist.offered; booking.cancelled;
   booking.released (тем, кто просил сообщить); после визита — «спасибо + отзыв» через 2 ч.
5. MessageTemplate в БД, редактируется в админке; рендер переменных {имя} {услуга} {дата} {время} {адрес}
   {ссылка_управления} {маршрут}; предпросмотр; «отправить себе тест».
6. Приём ответов (кнопки «Подтверждаю/Перенести/Отменить») через webhook'и каналов → manage-сервис.
7. Лог Message (статус доставки). Тексты сообщений НЕ содержат лишних ПДн.

Задача B (релиз 2): бот-ассистент владельца (MAX основной, Telegram опционально), docs/01-TZ.md §10.
- Доступ только StaffUser с подтверждённым номером (привязка через одноразовый код из админки).
- Команды: Сегодня, Завтра, Закрыть <дата>, Отпуск <с>–<по>, Новое мероприятие (пошаговый диалог),
  Акция (пошаговый диалог), Дайджест вкл/выкл.
- Любое изменяющее действие: черновик → карточка предпросмотра → [Подтвердить] [Изменить] [Отмена].
- Дайджест 21:00: завтрашние визиты, неподтверждённые, выручка за день, новые отзывы, свободные окна завтра
  с кнопкой «Предложить листу ожидания».
- Кросс-пост: после публикации мероприятия/новости — предложить «Опубликовать в VK / канал MAX?».
- Релиз 3: свободный текст → парсинг YandexGPT/GigaChat в структуру (БЕЗ ПДн в промпте), всё равно через подтверждение.
Тесты: юниты рендера шаблонов, фолбэк каналов, тихие часы, запрет маркетинга без согласия; моки адаптеров.
🚦 Покажи владельцу все тексты шаблонов одним списком, попроси переписать своими словами (голос бренда).
```
