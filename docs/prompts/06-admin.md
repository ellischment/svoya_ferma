# Промпт 06 — Админка PWA (builder)

```
Задача: webapp/ — админка по docs/01-TZ.md §9 и макетам Figma (если есть, иначе по docs/03-design-brief.md).
Пользователи — владелец и администраторы, в основном с телефона, НЕ технари.

1. PWA (manifest, иконки, офлайн-заглушка), нижний таб-бар: Сегодня · Расписание · Каталог · Афиша и акции · Гости; «Ещё».
2. Сегодня: визиты с цветом статуса подтверждения; действия Пришёл/Не пришёл/Позвонить (tel:)/Написать;
   свободные окна сегодня → «Предложить листу ожидания».
3. Расписание: день/неделя по ресурсам; перенос (drag на десктопе, long-press → «Перенести» на мобайле);
   «Закрыть день», «Отпуск» (диапазон → предпросмотр, кого затронет → подтверждение → сообщения клиентам).
   Ручная запись (гость пришёл/позвонил): 3 поля + согласие отмечается с источником «со слов/на месте».
4. Каталог: список услуг с тумблером вкл/выкл; карточка = Название, Категория, Длительность (чипы 30/45/60/90/120 + своё),
   Цена по локациям, «Изменить цену с даты», Фото (drag-drop, сжатие на клиенте до 2000px WebP → Object Storage),
   Описание (простой Markdown-редактор с кнопками Ж/К/список), SEO (свернуто, автозаполнение), «Только для новых»,
   Дублировать. Автосохранение черновика, «Опубликовать».
5. Афиша и акции: «Новое мероприятие» одним экраном (дата, время, место, мест, цена, ведущий, программа, фото,
   повторять еженедельно); акция (тип, значение, на что, сроки, текст баннера) с превью на сайте.
6. Гости: поиск, карточка (визиты, суммы, баллы, согласия с датами и версиями, каналы), «Удалить данные по запросу»
   (двойное подтверждение, AuditLog).
7. Настройки: правила открытия записи в виде человеческих предложений с полями-вставками
   («Открывать запись на следующий месяц [16] числа в [22:00]», «Ранний доступ за [2] ч для [листа ожидания]»),
   политика отмены, предоплата, часы работы, каналы, реквизиты, шаблоны сообщений, команда и роли.
8. Отчёты (релиз 2): выручка, заполняемость, no-show, источники, воронка записи.
9. После любого изменения публичного контента → вызов webhook пересборки website (debounce 60 с).
10. Undo 10 с для удалений/скрытий; все ошибки на русском; ≤ 3 тапа до любого частого действия; цели ≥ 44px.
Тесты: компонентные на формах (Zod-ошибки), e2e Playwright «владелец меняет цену с телефона» (390×844) ≤ 3 тапа
от главного экрана, «создать мастер-класс», «отпуск».
🚦 Дай владельцу ссылку на стенд и сценарий из 5 заданий; собери обратную связь в docs/feedback/admin-1.md.
```
