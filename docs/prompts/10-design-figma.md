# Промпт 10 — Дизайн в Figma (Claude Design / Claude с Figma MCP)

Вставить в Claude (с подключённым Figma MCP, навыки `figma-use`, `figma-generate-library`, `figma-generate-design`):

```
Спроектируй в Figma дизайн-систему и экраны для сайта и админки «Лесная ягодка / Своя ферма»: производство натуральных
сладостей (зефир, пастила без сахара, травяные сборы) и уютное пространство у леса в Псковской области, где проходят
мастер-классы, дегустации и экскурсии, и где можно онлайн записаться и купить продукцию.

Бриф: docs/03-design-brief.md (палитра с контрастами, типографика, фактура, компоненты, список экранов, микрокопирайт).
Контекст функций: docs/01-TZ.md §5, §6, §9.

Порядок:
1. Создай файл «Лесная ягодка — DS & Screens». Страницы: 00 Cover, 01 Tokens, 02 Components, 03 Site Mobile,
   04 Site Desktop, 05 Booking Flow, 06 Messages, 07 Admin PWA, 08 Dark.
2. Variables: цветовые токены (light/dark modes) ровно из брифа; spacing, radius, typography styles.
3. Библиотека компонентов с вариантами и auto-layout (список в брифе §5). Каждый компонент — состояния
   default/hover/focus/disabled/loading, где применимо. Цели касания ≥ 44px.
4. Экраны по приоритету из брифа §6. Мобайл 390, десктоп 1440. Используй реальные тексты из брифа §7,
   а не lorem ipsum. Цены и время — реалистичные (например «Мастер-класс „Пастила своими руками“ · 2 ч · 2 500 ₽ ·
   осталось 3 места»).
5. Ощущение: спокойно, тепло, «лесная кладовая»; жёлтая кнопка-таблетка — одна на экран; фоны секций
   чередуются лён/зефир; волны-разделители (стиль haikei Layered Waves) между секциями; ягоды-иллюстрации по краям.
   Никаких модальных попапов, кроме системной формы оплаты.
6. Для мастера записи нарисуй все состояния: выбор услуги, ближайшие окна + неделя, «запись откроется 16.09 в 22:00»,
   слот только что заняли, нет слотов → лист ожидания, форма «Кто вы» с двумя раздельными согласиями,
   оплата с таймером hold, успех.
7. Прототип-связи для флоу записи (mobile), чтобы можно было показать заказчику кликабельно.
8. В конце: скриншоты ключевых экранов и ссылка на файл; список решений, где ты отошёл от брифа, и почему.

Проверь контраст текста (AA) на каждом экране и отметь исключения.
```

После утверждения — `prompts/11-design-to-code.md`.
