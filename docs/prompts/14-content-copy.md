# Промпт 14 — Тексты сайта и сообщений (copywriter)

```
Используй навыки copywriting, cro, marketing-psychology, затем stop-slop для вычитки.
Контекст: docs/00-discovery.md (особенно 2.1, 2.4, 2.5 и E1–E6), docs/03-design-brief.md §7 (голос).
Исходные факты о бизнесе — ТОЛЬКО из текущего сайта и ответов владельца (docs/05-open-questions.md).
Не выдумывать цифры, награды, отзывы, количество клиентов. Где факта нет — [ФАКТ ОТ ВЛАДЕЛЬЦА: ...].

Голос: от первого лица хозяйки, тепло, спокойно, на «вы», конкретно, без канцелярита и восклицательных
знаков через слово. Не хвалить себя; говорить о госте и его ощущениях. Честно про ограничения (мест мало,
запись открывается по расписанию — потому что так спокойнее всем).

Выход в content/ (Markdown + frontmatter, чтобы грузить в админку/сайт):
1. Главная: H1 (с гео и интентом, ≤ 60 симв.), подзаголовок-обещание, микрокопия под CTA, «Как проходит визит» (4 шага),
   «От хозяйки» (≤ 120 слов), FAQ 7 вопросов (цена, длительность, дети, что взять, как добраться, отмена/перенос, подарок).
2. Шаблон страницы услуги и мероприятия: структура + 3 примера на реальных услугах.
3. О нас, Как добраться, Бонусы, Сертификаты.
4. Все шаблоны сообщений (подтверждение, напоминания, перенос, отмена, место освободилось, запись открылась,
   спасибо после визита, «давно не виделись» [маркетинг], день рождения [маркетинг]) — по 2 варианта, ≤ 300 символов,
   с переменными из docs/prompts/05.
5. Мета title/description для всех страниц (сверить с docs/seo/semantics.md).
Для каждого текста 2 варианта заголовка (для будущего A/B).
🚦 Владелец одобряет/правит; финальные тексты он может переписать своими словами — это желательно.
```
