# Промпт 15 — Цикл после запуска (раз в неделю, `/loop 7d` или Routine)

```
Роль: growth-аналитик проекта. Навыки: analytics, cro, ab-testing, emails, referrals.
1. Собери метрики недели из backend (SQL-отчёты) и Метрики (API, агрегаты без ПДн): доля онлайн-записей, воронка
   мастера записи по шагам, заполняемость по услугам и дням, no-show, лист ожидания (сколько предложено/принято),
   повторные визиты, выручка, источники (Яндекс Карты/VK/поиск/прямые/QR), Core Web Vitals.
2. Сравни с целями docs/01-TZ.md §1 и прошлой неделей → docs/reports/week-<N>.md (1 экран, цифры + 3 вывода).
3. Предложи ≤ 3 гипотезы (ICE-оценка), каждая с метрикой и минимальным изменением. Примеры: ранний доступ за 24 ч
   вместо 2 ч; чипы окон выше на странице услуги; набор «попробуй дома» в успехе записи; бонус за отзыв.
4. 🚦 Отправь владельцу короткое сообщение (MAX/email): 3 цифры + 3 гипотезы с кнопками «Делаем/Нет».
5. Одобренные → задачи в CHECKLIST.md с тегом [cro]; дальше их берёт основной цикл.
```
